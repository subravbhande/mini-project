## 1. Overview

The AgriSense Price Prediction Model forecasts **daily commodity market prices** for
Tomato and Onion across 6 markets in Sangli and Kolhapur districts.

It powers the **Phase 3 Decision Engine** - calculating Net Realizable Value (NRV):

```
NRV(t) = Q(t) x P(t) x (1 - quality_discount(t)) - StorageCost(t) - TransportCost
```

Where `P(t)` is the price predicted by this model.

### Why XGBoost?

| Factor | Decision |
|--------|----------|
| Dataset size (~1,650 rows) | XGBoost excels on small tabular data |
| Multiple markets/crops | One unified model with categorical encoding |
| Supply-demand interaction | Arrival quantity as a direct feature |
| Weather signals | All 13 weather columns natively included |
| Deployment | Simple pickle file - no GPU, no deep learning stack |

## 2. Architecture

```
Raw Data (Price CSV + Weather CSVs)
        |
        v
+-----------------------------+
|  prepare_weather_data.py    |  Parse stacked CSVs -> clean daily weather
+-------------+---------------+
              |
        v
+-----------------------------+
|  PriceModel.load_and_       |  Join price + weather on (date x district)
|  prepare_data()             |  Engineer 49 features
+-------------+---------------+
              |
        v
+-----------------------------+
|  XGBoost Regressor          |  Train on 1,159 rows
|  (400 trees, depth=6)       |  Test on last 60 days (350 rows)
+-------------+---------------+
              |
        v
+-----------------------------+
|  PriceModel.predict()       |  Rolling 1-14 day forecast
|                             |  Returns PriceForecast dataclass
+-----------------------------+
```

## 4. Feature Engineering

The model uses **49 features** across 6 groups:

### 4.1 Price Lag Features
| Feature | Description |
|---------|-------------|
| `modal_price_lag1` | Yesterday modal price |
| `modal_price_lag7` | Price 7 days ago |
| `modal_price_lag14` | Price 14 days ago |
| `modal_price_roll7` | 7-day rolling mean |
| `modal_price_roll14` | 14-day rolling mean |
| `modal_price_std7` | 7-day rolling std dev (volatility) |
| `modal_price_std14` | 14-day rolling std dev |
| `min_price_lag1/7/14` | Min price lags |
| `max_price_lag1/7/14` | Max price lags |
| `price_range` | Max - Min (daily spread) |

### 4.2 Supply Features
| Feature | Description |
|---------|-------------|
| `Arrival Quantity` | Daily market arrivals (MT) |
| `arrival_lag1` | Yesterday arrivals |
| `arrival_roll7` | 7-day rolling avg arrivals |

### 4.3 Temporal Features
| Feature | Description |
|---------|-------------|
| `month` | Month number (1-12) |
| `month_sin` / `month_cos` | Cyclical encoding of month |
| `dow_sin` / `dow_cos` | Cyclical encoding of day-of-week |
| `week_of_year` | ISO week number |
| `day_of_year` | Day number (1-365) |
| `quarter` | Quarter (1-4) |
| `is_harvest_season` | 1 if peak harvest month for that crop |

### 4.4 Weather Features
| Feature | Description | Price Impact |
|---------|-------------|--------------|
| `temp_mean` | Daily mean temperature (C) | Affects shelf life |
| `temp_max` | Daily max temperature (C) | Heat stress on produce |
| `temp_min` | Daily min temperature (C) | |
| `precipitation_sum` | Total rainfall (mm) | Transport disruption |
| `rain_sum` | Actual rain excluding snow (mm) | |
| `precipitation_hours` | Hours of rain per day | Road blockage proxy |
| `humidity_mean` | Daily mean relative humidity (%) | Spoilage risk |
| `evapotranspiration` | ET0 (mm) | Crop water stress |
| `weather_code` | WMO code (0=clear, 61=rain, 95=storm) | |
| `soil_moisture_0_to_100cm` | Deep soil moisture | Upcoming yield signal |
| `soil_moisture_0_to_7cm` | Root zone moisture | |
| `soil_moisture_7_to_28cm` | Mid-zone moisture | |
| `soil_moisture_28_to_100cm` | Sub-soil moisture | |

### 4.5 Weather Lag / Rolling
| Feature | Description |
|---------|-------------|
| `temp_mean_lag3` | Temperature 3 days ago |
| `precipitation_sum_roll7` | 7-day cumulative rainfall |
| `humidity_mean_roll7` | 7-day mean humidity |
| `temp_mean_roll7` | 7-day mean temperature |

### 4.6 Categorical (Label Encoded)
| Feature | Values |
|---------|--------|
| `Commodity_enc` | Onion=0, Tomato=1 |
| `Market_enc` | Islampur, Kolhapur, Palus, Sangli, Sangli-Phale-Bhajipala, Vadgaonpeth, Vita |
| `District_enc` | Kolhapur=0, Sangli=1 |

## 11. Backend Integration (Node.js)

The backend (Node.js + CommonJS, port 5000) communicates with Python via a
**child_process spawn** bridge that pipes JSON in/out.

### Step 1 - Python bridge script
Create `ml_service/predict_api.py`:

```python
"""
CLI bridge called by Node.js via child_process.
Reads JSON from stdin, returns PriceForecast JSON to stdout.

Usage:
  echo '{"commodity":"Tomato","market":"Kolhapur","district":"Kolhapur","horizon_days":7}' | python predict_api.py
"""
import sys, json, os
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from models.price_model import PriceModel

model = PriceModel.load()

payload = json.loads(sys.stdin.read())
forecast = model.predict(
    commodity=payload["commodity"],
    market=payload["market"],
    district=payload["district"],
    start_date=payload.get("start_date"),
    horizon_days=payload.get("horizon_days", 7),
    weather_forecast=payload.get("weather_forecast"),
)
print(json.dumps(forecast.to_dict()))
```

### Step 2 - Node.js ML service
Create `backend/src/services/mlService.js`:

```javascript
const { spawn } = require("child_process");
const path = require("path");

const ML_ROOT = path.join(__dirname, "../../../ml_service");
const PYTHON  = process.env.PYTHON_PATH || "python";
const SCRIPT  = path.join(ML_ROOT, "predict_api.py");

/**
 * Call the XGBoost price prediction model.
 * @param {Object} params
 * @param {string} params.commodity       - "Tomato" | "Onion"
 * @param {string} params.market          - e.g. "Kolhapur", "Sangli"
 * @param {string} params.district        - "Kolhapur" | "Sangli"
 * @param {string} [params.start_date]    - ISO date string
 * @param {number} [params.horizon_days]  - 1-14 (default: 7)
 * @param {Array}  [params.weather_forecast] - Array of daily weather dicts
 * @returns {Promise<Object>} PriceForecast JSON
 */
function getPriceForecast(params) {
  return new Promise((resolve, reject) => {
    const proc = spawn(PYTHON, [SCRIPT], { cwd: ML_ROOT });

    let stdout = "";
    let stderr = "";

    proc.stdout.on("data", (d) => (stdout += d.toString()));
    proc.stderr.on("data", (d) => (stderr += d.toString()));

    proc.on("close", (code) => {
      if (code !== 0) {
        return reject(new Error(`ML process failed (code ${code}): ${stderr}`));
      }
      try {
        resolve(JSON.parse(stdout));
      } catch (e) {
        reject(new Error(`Failed to parse ML output: ${stdout}`));
      }
    });

    proc.stdin.write(JSON.stringify(params));
    proc.stdin.end();
  });
}

module.exports = { getPriceForecast };
```

### Step 3 - Price routes
Create `backend/src/routes/priceRoutes.js`:

```javascript
const express = require("express");
const router  = express.Router();
const { getPriceForecast } = require("../services/mlService");

// GET /api/price/forecast?commodity=Tomato&market=Kolhapur&district=Kolhapur&days=7
router.get("/forecast", async (req, res) => {
  const { commodity, market, district, days, start_date } = req.query;

  if (!commodity || !market || !district) {
    return res.status(400).json({ error: "commodity, market, district are required" });
  }

  try {
    const forecast = await getPriceForecast({
      commodity,
      market,
      district,
      start_date: start_date || null,
      horizon_days: parseInt(days) || 7,
    });
    res.json({ success: true, data: forecast });
  } catch (err) {
    console.error("[PriceForecast Error]", err.message);
    res.status(500).json({ success: false, error: err.message });
  }
});

// POST /api/price/forecast  (with weather payload)
router.post("/forecast", async (req, res) => {
  const { commodity, market, district, start_date, horizon_days, weather_forecast } = req.body;

  if (!commodity || !market || !district) {
    return res.status(400).json({ error: "commodity, market, district are required" });
  }

  try {
    const forecast = await getPriceForecast({
      commodity, market, district,
      start_date, horizon_days, weather_forecast,
    });
    res.json({ success: true, data: forecast });
  } catch (err) {
    console.error("[PriceForecast Error]", err.message);
    res.status(500).json({ success: false, error: err.message });
  }
});

module.exports = router;
```

import axios from "axios";

const BASE_URL = import.meta.env.VITE_API_URL || "http://localhost:5000";

export async function fetchPriceForecast(commodity, market, district, days = 7) {
  const res = await axios.get(`${BASE_URL}/api/price/forecast`, {

### Step 2 - React custom hook
Create `client/src/hooks/usePriceForecast.js`:

```javascript
import { useState, useEffect } from "react";
import { fetchPriceForecast } from "../services/priceApi";

export function usePriceForecast(commodity, market, district, days = 7) {
  const [forecast, setForecast] = useState(null);
  const [loading, setLoading]   = useState(false);
  const [error, setError]       = useState(null);

  useEffect(() => {
    if (!commodity || !market || !district) return;
    setLoading(true);
    setError(null);
    fetchPriceForecast(commodity, market, district, days)
      .then(setForecast)
      .catch((e) => setError(e.message))
      .finally(() => setLoading(false));
  }, [commodity, market, district, days]);

  return { forecast, loading, error };
}
```
